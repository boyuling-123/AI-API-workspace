# 测试数据说明

本目录是给平台「测评能力」做测试用的**批量导入 Excel** 假数据。

> 表头约定：`prompt`（提示词）、`image_url`（图片链接，含图时填）；其余列会作为算法参数进入 extraFields。

| 文件 | 用途 | 重点验证 |
| --- | --- | --- |
| `批量_纯文本_10条.xlsx` | 纯文本提示词 | 大模型文本输出对比、并发运行 |
| `批量_含图_多模态_6条.xlsx` | 带公网图片 URL | 多模态模型（Qwen3.6 Plus / Kimi）读图、纯文本模型置灰 |
| `批量_算法参数_文生图_5条.xlsx` | 额外 num_images / style 列 | 算法 API 混选、算法参数透传 |
| `批量_脏数据_边界测试.xlsx` | 空行/缺列/超长/特殊字符 | 解析健壮性、空行 warning 提示 |

重新生成或修改数据后重跑：`node 测试数据/gen_excel.mjs`
