# 模型评测平台 · 设计预览版

一套全新美化界面的**静态演示**，用真实功能布局 + 假数据，独立于现有 `src/`，可直接用浏览器打开看效果。

## 怎么看

```bash
open design-preview/index.html   # macOS
# 或直接双击 index.html
```

右上角 ☀️/🌙 按钮切换**亮 / 暗双模式**（自动跟随系统，选择会记忆）。

## 设计规格

由 `skills/ui-ux-pro-max` 设计系统驱动，针对评测平台推荐：

| 项 | 取值 |
|----|------|
| 风格 | Data-Dense Dashboard（数据密集仪表盘） |
| 主色 | 专业蓝 `#1E40AF` / 次蓝 `#3B82F6` |
| 点缀 | 琥珀 `#F59E0B`（CTA / 推荐高亮） |
| 字体 | Fira Code（标题/数据）+ Fira Sans（正文） |
| 主题 | 亮 / 暗双模式（class 策略，localStorage 持久化） |

## 布局：两页式 + 抽屉（v2）

为避免单页堆太多功能造成混乱，拆成两个干净页面，顶部 Tab 切换：

- **① 配置评测**：输入区（单条/批量）→ 算法参数 → 评测目标多选 → 「开启 AI 评价」小开关 → 吸底运行操作条（并发/试运行/批量）。
- **② 结果与历史**：运行结果对比（卡片/表格切换、多目标横向对比、导出 Excel）+ 历史任务列表。

**AI 智能评价**：主界面只放一个开关，**勾选后从右侧滑出抽屉**配置（测评需求/Prompt/AI 生成/裁判模型/范围/评价结果/开始评价），不勾完全隐藏。点遮罩或 Esc 可关闭。

> `index_v1_单页版_备份.html` 是最初的单页版，留作对比，可删。

## 说明

- **纯静态演示**，所有数据为假数据，不接任何后端。
- **完全不碰** `src/` 任何文件，满意后再决定是否迁移到 React 组件。
- 技术：单 HTML + Tailwind CDN，无需构建。可用的交互：Tab 切换、AI 评价开关 + 抽屉、主题切换。
