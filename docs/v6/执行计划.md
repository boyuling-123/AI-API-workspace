## Agent Loop

每轮自动执行以下循环：

1. **Observe**：读取最新 main、未合并 PR、CI、契约和底座能力核验表。
2. **Select**：只领取 1 至 3 个 Ready 且共享同一验收路径的能力。
3. **Specify**：先写验收条件、异常路径、数据边界和不包含范围。
4. **Implement**：从真实源文件实现，不复制生产逻辑到测试。
5. **Verify**：单测、集成、Playwright、可访问性、Secret Scan、依赖和生产构建。
6. **Review**：检查完整 Diff、上游许可、能力声明、回滚和视觉证据。
7. **Deliver**：提交、推送、创建 PR；CI 全绿且无未解决审查后正常合并，不强推或改写历史。
8. **Record**：更新核验表、任务台账、开发纪实和下一 Ready 节点。

遇到失败先在当前节点修复和复验；只有外部身份、不可逆产品决策或真实付费调用才需要用户介入。普通分支、PR、CI 和安全合并不重复请求确认。

## 时间与自动化

本轮自动化持续到 2026-09-09 09:00（Asia/Shanghai）。若全部 Ready 工作提前完成或遇到必须由用户处理的外部阻断，自动化应暂停并给出单一、明确的下一步；不得用空 PR 或重复轮询填满时间。
