# EvalScope 底座能力核验表

## 使用说明

处置结论只允许 `直接复用`、`扩展适配`、`自主补充`、`暂不支持`。证据成熟度分为“源码核验、基线测试、业务试跑、发布验收”；只有达到发布验收，才可以对外称为 v6 已验证能力。

当前所有结论均基于固定上游提交 `c31f0f946c09bc087f856a017637ac157b5459a5`，尚未完成白底商品图业务试跑，因此没有能力被标记为直接复用。

## 升级规则

每一行升级为“发布验收”必须同时补齐：固定提交或本地 SHA、真实源文件测试、业务输入与期望输出、失败路径、截图或 Trace、CI 链接、回滚说明。Mock 可以验证编排，但不能替代至少一次不产生费用的真实底座执行。
