# v6.0 分阶段验收用例

## 通用门禁

每个功能 PR 均执行：许可和来源检查、Secret Scan、依赖审计、lint、typecheck、真实源码单测、适用集成测试、生产构建、Playwright 主路径与可访问性、截图或 Trace 人工复核、回滚验证。测试默认使用固定 Mock 或合成数据。

## P0 底座与可信运行

| ID | 场景 | 验收条件 |
| --- | --- | --- |
| P0-001 | 固定上游基线 | Git SHA 与清单一致；前后端可在隔离环境启动；无用户数据和密钥 |
| P0-002 | 白底商品图最小试跑 | 合成图片输入经过 DatasetVersion、TargetVersion、RunSpec、RunItem 和独立 EvaluationRecord 完成闭环 |
| P0-003 | 失败隔离 | 一个 Case 失败不丢失其他结果；错误类型、Attempt 和证据可下钻 |
| P0-004 | 暂停保留 | 暂停后已完成数据仍可见；恢复只执行剩余项，进度分母不变化 |
| P0-005 | 输出复用 | 新增 Evaluator 只产生 Judge 调用，不重复调用 Target |
| P0-006 | 不可变版本 | 修改草稿后历史 Run 仍解析为原版本；继续任务不读取新草稿 |
| P0-007 | 幂等提交 | 重复提交同一幂等键不创建第二个 Run；payload 变化返回冲突 |
| P0-008 | 文件真相源 | 删除 SQLite 后重建，关键对象数、摘要和关联完全一致 |
| P0-009 | 大数据分页 | 合成大清单以流式方式导入和分页；浏览器不加载完整文件 |
| P0-010 | 中文信息架构 | 一个一级标题、稳定侧栏、无空壳页面；375 至 1440 宽度可用且无严重 WCAG 问题 |
| P0-011 | 安全基线 | 依赖风险已修复或有明确时限例外；日志、Trace、导出和错误均不泄露密钥 |
| P0-012 | 最小 Judge 校准 | 黄金集结果可复算；发布需显式确认，原始 Judge 记录不可改写 |

## P1 Agent 与外部召唤

| ID | 场景 | 验收条件 |
| --- | --- | --- |
| P1-001 | 数据导入 Skill/MCP | 识别格式、预览映射并确认输入字段、标准答案字段、评价模式和缺失策略后才导入 |
| P1-002 | Deep Link | URL 只含稳定 ID 与视图参数；打开后从本地服务加载完整草稿 |
| P1-003 | Action 同源 | Web、MCP 和 API 对同一 payload 得到相同校验、错误码与幂等结果 |
| P1-004 | 助手安全确认 | 助手可以规划和预检，但不能代替用户确认付费跑批或 Judge |
| P1-005 | 人工复核 | 人工结论作为只追加覆盖层，保留 AI 原分、原因、操作者和版本链 |

## P2 优化闭环

| ID | 场景 | 验收条件 |
| --- | --- | --- |
| P2-001 | Prompt/Skill 资产 | 版本、适用 Target、数据集和评估证据可追溯 |

| P2-003 | 回归保护 | 优化版本在关键切片无回归，失败时不自动发布 |

## P3 观察与安全

| ID | 场景 | 验收条件 |
| --- | --- | --- |
| P3-001 | Trace/Replay | Agent 步骤、工具、耗时、重试和错误可还原，Replay 不默认调用真实服务 |
| P3-002 | 会话 | 多轮输入与 Run/Trace 关联且可分页迁移 |
| P3-003 | 红队 | 攻击集、风险类别、拒答策略和复核证据版本化，不混入普通质量分 |

## 白底商品图合成夹具

首个业务夹具使用代码生成的几何商品图，不包含个人图片、版权素材或远程 URL。目标适配器使用确定性本地 Mock 输出一张白底结果图；独立评估器检查尺寸、背景像素占比、主体边界和输出格式。另设置一条故意失败样本验证错误隔离。

该夹具验证的是 EvalScope 产品接线，不证明真实生图模型质量，也不产生外部调用费用。
