# F-STORE-001 不兼容本地项目保留

## 需求与范围

平台是中文、本地优先的工作台。打开页面不应删除旧项目；无法加载的数据也不等于可以清理的数据。本节点修复兼容性检查的隐式删除，仍使用原 IndexedDB 数据库及 Schema，不新增后端、不自动迁移或备份、不读取用户实际浏览器数据库做验收。

## 验收条件

| 编号 | 条件 | 测试证据计划 |
| --- | --- | --- |
| AC1 | 目录读取只读分类；不兼容版本、缺字段和缺更新时间索引的记录原样保留并计数 | 真实 Dexie/内存 IndexedDB 读前后快照、禁止写入断言 |
| AC2 | 加载兼容记录中更新时间最新者，同时间按 ID 逆序；全部不兼容时另建项目，不覆盖旧项目 | 单测、真实浏览器 IndexedDB 刷新路径 |
| AC3 | 保存时在同一读写事务中阻止覆盖同 ID 的不兼容记录；非法新记录拒绝写入 | 真实存储事务单测 |
| AC4 | 中文提示保留数量，明确不是迁移或备份，当前项目导出不包含保留记录；新项目编辑后提示不消失 | Playwright、截图、WCAG、390px |
| AC5 | 读写失败显示固定可操作提示，不把原始异常/记录字段写入日志或 UI；保存失败不伪报成功 | 错误分类单测、浏览器故障注入 |
| AC6 | 现有保存、刷新、显式删除语义回归；全量质量及远端 CI 通过后才合并 | quality、Playwright、CI |

兼容性仅检查当前版本、ID/名称、有限数值的创建/更新时间，以及 targetConfigs/tasks/evaluations 三个必需数组；新增可选数组不要求存在。这不是嵌套业务内容的完整验证。未知记录不修复、不脱敏改写；不能恢复此前旧代码已经删除的数据，也不能防止用户主动清理浏览器数据或浏览器配额淘汰。
