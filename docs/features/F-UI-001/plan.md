## 本轮纪实

- 纠正之前交付偏差：夜间观测和导览增量并非用户要求的主界面改造。
- 主导航从七个横向动作 Tab 改为按 PRD 业务对象分组。默认页从长跑批表单改为运行记录；原表单放入“新建任务”。
- 将管理入口拆出资源、外部接入、能力状态。移除主界面装饰宠物与重复平台标题。
- 现有 E2E 从旧 Tab 文案迁移到真实一级链接/二级链接，不保留隐藏旧导航以骗过测试。
- 首次新增测试暴露移动端三个图标按钮缺少可访问名称，已增加明确标签；另修正测试中的旧占位符定位。失败产物不作为通过证据。
- 新增二级导航适配来源声明，不能将适配组件说成整个 Langfuse 前端移植完成。
- 回归中发现“报告返回运行记录”的旧测试假设二级导航跨页面常驻，改为真实一级“评测任务”入口；同时关闭实验/归档页的 Ant Design 装饰过渡，避免启用按钮和弹窗文字在过渡帧呈低对比度。
- 更快的页面切换暴露评价完成后仍等待 600ms 防抖落盘的窗口；完成记录改用现有 Repository 即时写入队列，回归明确等待本次“已自动保存”再刷新，不以旧保存提示冒充新记录已落盘。
