# F-OBS-004 观测 JSON 本机回读

状态：已验证，本地完整门禁与 [PR #53](https://github.com/boyuling-123/AI-API-workspace/pull/53) 最终 CI 全通过，已正常合并。[验收证据](../../evidence/pr-portable-observation/README.md)。分支 `codex/feat-portable-observation`，基线 PR #52 合并后的 main。仅补已导出结果重新打开的可迁移闭环。

## 契约与边界

- 仅接受本平台两种 `schemaVersion: 1` Mock 观测 JSON：手动 OTel 三组/14 步、LangGraph 两组/7 步。沿用已固定的 SDK/框架版本和合成字段白名单，不接收业务数据、任意 JSON 或 OTLP。
- 单文件最多 64 KiB，最多 14 步；读取前检查大小，解析前限制嵌套并拒绝重复 JSON 键。严格验证字段、ID、时间、父子关系和场景摘要。缺失/未知/损坏不跳过、不补空、不反射原文或底层异常。
- 选择文件后显示来源声明、版本、调用链/步骤数、替换范围。确认前不替换；取消、校验失败、读取失败均保留当前结果。读取/预览期间不允许启动实验；取消后过期读取不得回填。
- 确认只替换当前页面结果，不落库、不调用 API/模型、不读取归档正文。离开页面会丢失，仍需下载携带。
- 文件不能证明是谁运行的。所有回读结果强制附带 `provenance: { kind: "local-file", verification: "unverified" }`；页面标明“外部文件回读，来源未认证”，`source/framework` 仅为文件声明。再次导出保留标记；没有该标记的旧文件回读也必须补标记。它不是数字签名，不能防止文件在平台外被修改。
- 不改变现场运行导出原契约；新增可选 provenance 为兼容扩展。成功重新运行会产生新的现场结果；失败/取消运行保留旧结果及其来源标记。

## 验收

直接测试真实导出器和实际 LangGraph 子进程输出，不复制运行实现。覆盖两个格式的往返、损坏/重复键/未知字段/大小/嵌套/图结构/时间、来源标记不能洗白。Playwright 实际下载再选择文件、预览、取消、确认、再导出、异常恢复与过期读取、移动端、键盘、axe、截图/Trace。回读路径零 API；完整本地门禁和最终 head GitHub CI 成功后才升级已验证。

回滚：普通 revert 本主题，无数据库迁移或数据删除；保留文件仍是 JSON，旧页面可继续运行及下载。
