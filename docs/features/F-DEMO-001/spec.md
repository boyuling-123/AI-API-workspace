# F-DEMO-001 中文产品演示导览

状态：已验证，本地完整门禁与 [PR #52](https://github.com/boyuling-123/AI-API-workspace/pull/52) 最终 CI 全通过，已正常合并。[测试与回滚证据](../../evidence/pr-interview-walkthrough/README.md)。分支 `codex/feat-interview-walkthrough`，基线 PR #51 合并后的 main。

## 需求

面试时用约 4 分钟讲清产品判断、真实操作、开源复用和能力边界，而不是逐个念菜单。独立 `/interview-demo` 入口，复用现有平台总览、历史归档、观测实验室、只读工具和 GitHub 证据。首页只增加一个次级入口，不增加 API 大看板或模型配置。

## 范围

- 五个中文章节：产品定位、历史规模、失败定位、助手互联、工程证据。用 query 中的固定 chapter ID 定位，刷新/返回可继续；无记录正文或完整数据进入 URL。
- 当前章节是导航状态，不是任务验收/自动完成进度；建议时长是讲解参考，不是测得的执行耗时。
- 每章包含“讲什么、怎么操作、看什么证据、不要夸大什么”。未知或重复 chapter 回到定位并说明，不反射原始 query。
- 导览不调用 API、不运行模型、不打开正文、不读取浏览器项目数据库。用户点击归档入口后，已有归档页自动读取索引与首屏，明确提示；正文仍沿用确认门禁。
- 现有三个新工作台页面共用中文导航，导览链接带对应 chapter；不改变原页面功能、默认跑批首页或已有数据。
- 一键下载中文 Markdown 讲解手册，仅固定产品说明/路由/公开证据，不含真实数据、机器路径、密钥或捏造实验结果。
- 不把真实框架 + Mock 节点称为真实模型评测，不把两个 MCP 只读动作称为完整平台 Assistant；不开新的存储后端。

## 验收

真实源码测试章节解析、下载内容与可追溯路径；Playwright 实际点击总览入口和全部本机路由、回到对应章节、刷新、未知参数、Markdown 下载、键盘/移动端/WCAG。导览零 API 请求，归档只允许既有索引接口且不读正文，观测/助手不自动执行。截图或 Trace、本地质量门禁、最终 PR CI 齐备后才标为已验证。

回滚：普通 revert 本主题，移除新导览并恢复旧导航，无数据迁移、写入或删除。
