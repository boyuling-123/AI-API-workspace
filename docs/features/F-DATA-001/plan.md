# F-DATA-001 实施计划与审查

## 实施单元

| 单元 | 实现 | 验收 |
| --- | --- | --- |
| 数据契约 | 摘要、页、元数据行、显式正文分离 | 默认 DTO 不含原始字段 |
| 本地读取器 | 固定包装 JSON、文件限额、顺序核对、哈希快照 | 畸形、重复、超量、变化、链接均测试 |
| 读取 API | 只读操作、数字索引、同源/回环约束、无原始日志 | 真实 route 请求测试 |
| 中文页面 | 独立轻量入口、摘要/类别/表格/确认弹窗 | 实际 API 的浏览器用户路径 |
| 开发隔离 | CI 自建合成夹具，不复用未知测试服务器 | 业务数据配置始终 Git 忽略 |
| 本机验收 | 授权目录只读连接，核对全量与分页大小 | 只记录汇总，不生成模型成绩 |

## 已发现与修复

- 第一轮 typecheck 发现测试使用 `Array.entries()` 的迭代与仓库低 target 不兼容；改为索引循环，不全局修改编译目标。
- 清单聚合只作为差异提示；添加安全整数检查，避免不可信汇总溢出。
- 服务非 JSON 错误响应显示可理解的中文提示，不直接把解析异常当成正文。
- 首轮真实 API E2E 发现 Next 内部 URL 的主机别名和浏览器 Host 不同，造成合法请求被 403 拒绝。分别验证两者都为回环地址且端口一致，再将 Origin 严格绑定浏览器 Host；新增别名与端口/伪造 Host 单测，不取消跨站保护。
- 本机联调发现超时、限流等已有状态未被翻译；补充白名单中文标签，保留未知状态为未分类，不直接输出任意历史状态文本。增加真实函数单测与浏览器超时标签断言后重新执行完整门禁。

## 回滚

代码通过普通 revert 回滚本 PR；移除新增页面入口和只读服务即可。归档源文件及既有 IndexedDB 均不变，无数据库迁移，不需要数据回滚。测试夹具与本机路径配置均不进入提交。

当前无全局检索、Evidence 文件读取、后台存储、MCP 接线和真实模型实验；这些保持下一节点，不夹带交付。
