# 中文产品演示导览

入口：在本机工作台打开 `/interview-demo`，或从“平台总览”点击“面试演示导览”。导览提供讲解顺序，不会自动运行任务，也不是演示完成记录。

## 4 分钟讲清什么

| 章节 | 要表达的产品判断 | 实际动作 | 必须说清的边界 |
|---|---|---|---|
| 产品定位 | 产品经理需要组织测试集、对比输出、复核证据，而不是再维护一套重型平台 | 打开现有总览 | 仍有本机 Next API；不是纯静态网页、完整 Langfuse Fork 或 20GB 执行系统 |
| 历史规模 | 大规模历史应分页查看，统计口径先于漂亮数字 | 打开归档、核对来源/索引数/去重 ID/清单偏差 | 点击入口会读摘要与首屏索引；不自动读正文。历史数不是本次模型调用数，去重 ID 不是业务用例去重 |
| 失败定位 | 最终成功不代表中间没有错误，失败和恢复都要留痕 | 手动运行真实 LangGraph 的固定实验，定位首次工具失败及第二次恢复 | 真实框架、固定 Mock 节点，模型调用 0；耗时不是模型排名，Token/成本未测量 |
| 助手互联 | AI 友好应共享业务 Action，不是包装每个视觉按钮 | 在工具页手动查能力或归档统计 | 只有两个只读 MCP 动作，不是完整 Assistant；外部宿主信任需另外确认 |
| 工程证据 | 复用、自己的改动与测试都应可以核对 | 看来源/许可、Spec、Diff、截图/Trace、最终 CI 和 PR | 自己仓库的 PR 不等于上游贡献；自动化自检不等于独立人类评审 |

章节通过固定 `chapter` ID 定位，刷新和从功能页返回可继续。未知/重复章节回到产品定位并提示，不把原始参数显示到页面。页面只高亮当前章节，不假装已经替用户完成了操作。

## 下载与演示安全

“下载中文讲解手册”生成 Markdown，正文与网页共用 `src/lib/interviewGuide.ts`，包含全部章节、固定功能路由与公开工程证据。下载不包含本机归档、用户项目、机器路径、密钥或动态成绩。下载失败可重试，不修改数据。

导览与手册均可在已有本机运行环境中浏览；公开 GitHub 证据需点击才打开外网。缺失归档配置必须展示真实错误，不用合成计数替代。面试时可以只演示归档统计，不打开可能含业务或个人信息的正文。

建议演示前自行核对设备与当前工作台地址；不要在投屏时打开环境文件、外部宿主凭证或真实业务正文。首次安装依赖仍可能需要网络，不能将本机运行称为已完成离线安装分发。
